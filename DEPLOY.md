# Publicar Football Myths vs Data

La aplicación usa Streamlit y el dataset limpio que ya está en la raíz del repositorio.

## Requisitos

- Acceso a la cuenta de GitHub propietaria del repositorio.
- Una cuenta en Streamlit Community Cloud.
- En la raíz deben estar `app.py`, `datos_limpios.csv` y `requirements.txt`.

## Pasos

1. Abre [Streamlit Community Cloud](https://share.streamlit.io/).
2. Inicia sesión y autoriza la conexión con GitHub si la plataforma lo solicita.
3. Selecciona **Create app**.
4. Elige el repositorio `jormartinez109/PROYECTO-EDA-FUTBOL`, la rama `main` y el archivo principal `app.py`.
5. Pulsa **Deploy** y espera a que se instalen las dependencias.
6. Comprueba que carga la app, que se ven las seis pestañas y que los filtros funcionan.
7. En la configuración de la aplicación, revisa la opción de acceso/compartición y habilita el acceso público si está disponible para esa app.

## Importante sobre privacidad

El repositorio de GitHub puede permanecer privado, pero la app publicada y los datos que utiliza deben tratarse como contenido compartido públicamente con quienes tengan acceso a la aplicación. Antes de publicar, comprueba que el CSV y el contenido no contienen datos personales ni material que no quieras compartir.
